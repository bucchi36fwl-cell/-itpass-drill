# ITパスポート演習帳

ITパスポート試験の3分野（ストラテジ系・マネジメント系・テクノロジ系）の要点まとめと、四肢択一の演習問題をまとめた学習用Webアプリです。

## 機能

- 分野別の要点まとめ（公式・用語・ポイント）
- 演習モード：分野別、ランダム10問、ミニ模試20問（時間計測つき）、間違えた問題の復習
- 学習記録（正答率）は、使っているブラウザ内に保存されます

## 構成

`index.html` の1ファイルだけで動きます。ビルドは不要です。

## 注意

個人が作成した非公式の学習教材で、IPA（独立行政法人情報処理推進機構）とは関係ありません。問題は学習用に作成したオリジナル問題です。最新の出題範囲は公式のシラバスで確認してください。
